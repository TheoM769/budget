# Labelizer

Catch-up mode. Work through unlabeled transactions one by one until inbox is zero.

## What the user wants to do

After an import, many transactions have no label. The Labelizer surfaces them one at a time and makes it fast to classify each one — or create a rule that handles a whole batch automatically.

## How it works

- Launch with `labelize` from the home screen
- Shows only unlabeled transactions
- One transaction displayed as a card at a time: date, description, amount
- Label hierarchy visible in the right panel for reference
- Counter shows remaining unlabeled transactions

## Outcome

All transactions labeled. Analytics become accurate. Rules created during the session reduce future labeling work.
