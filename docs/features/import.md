# Import

Bring bank statement exports into the tracker.

## What the user wants to do

Got a CSV from the bank? Import it. New transactions land in the tracker, duplicates are skipped automatically.

## How it works

- Launch the Import window from the home screen (`import`)
- Type `@` followed by a file path — Tab autocompletes the filesystem. By default, the root path for the @ search is the data/ folder.
- `~/` expansion supported
- Press Enter to import
- Display the number of imported transactions.
- Automatically apply defined rules to all imported transactions.

## Outcome

Raw bank data becomes queryable, labelable transactions inside the tracker.
