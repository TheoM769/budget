# Transactions

Full picture of money movement. Browse, search, fix, and manage all transactions.

## What the user wants to do

See everything. Find a specific transaction, correct a bad description, remove a duplicate, assign or fix a label — all from one place.

## How it works

- Launch with `transactions` from the home screen
- Paginated list (15/page): date, description, amount, label
- Navigate with up/down keys, page with left/right arrow keys
- Select one or multiple transactions with Space
- Filter by description (regex supported) with `f`

## Outcome

Clean, accurate transaction list ready for labeling and analysis.
